
# Attack On Titan — Fan Website

A simple fan-made website inspired by Attack on Titan, built using HTML, CSS, and JavaScript.

## Features
- Simple dark-themed design
- Start Exploring button
- Character selection
- Interactive messages

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project Status
Beginner project — more features will be added in the future.
